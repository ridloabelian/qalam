# Qalam

Personal Prompt Engineering System.

## Purpose

Sistem prompt engineering personal yang mengubah rough drafts menjadi precision-crafted, elite-grade prompts.

## Tech Stack

- **Format:** Markdown-based knowledge system
- **Theme:** Gold × Navy design system

## Key Features

- `prompts/raw/` — draft dumping ground
- `prompts/refined/` — optimized outputs
- `templates/` — reusable prompt frameworks by use case
- `examples/` — before/after showcases
- Design system dengan defined hex tokens (Primary Gold `#D4AF37`, Navy Dark `#001F3F`, dll.)

## Key Conventions

- Markdown-based organization
- Raw → Refined workflow
- Template reuse untuk konsistensi
- Gold × Navy aesthetic untuk branding
